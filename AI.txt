AI Usage

Claude Code (Anthropic) was used as a coding agent throughout this project. Roughly 90% of the codebase — the React components, reducer-based state management, PubMed/Alliance Genome API client wrappers, and sample data fixtures — was AI-generated; the remainder is scaffolding and configuration I wrote myself. My role was to direct the requirements and feature scope, review and test the generated code in the browser for correctness, make architectural and product decisions (data flow, file organization, deployment strategy), and manage git commits, pushes, and deployments.
