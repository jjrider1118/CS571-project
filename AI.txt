AI Usage

Claude Code (Anthropic) was used as a coding agent throughout this project, including the initial app build and all subsequent feature work and bug fixes (references toggle, filtering, collapsible cards, and related UI/state fixes), as well as diagnosing and resolving the GitHub Pages deployment setup. Roughly 90% of the codebase was AI-generated; the remainder is scaffolding and configuration I wrote myself. My role throughout was to direct the requirements and feature scope, relay check-in feedback and bug reports, review and test the generated code (including live in-browser verification), make architectural and product decisions, and manage git commits, pushes, and deployments.
